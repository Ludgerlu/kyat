# KYAT SERVICE PREMIUM

## Description du projet

KYAT SERVICE PREMIUM est une application web professionnelle destinée à présenter les services de l'entreprise et faciliter la prise de contact avec ses clients.

Le site met en avant ses expertises en recrutement et placement du personnel, conseil en ressources humaines, développement des compétences, conseil et développement informatique, ainsi que les prestations de services diverses.

## Objectif

L'objectif principal du projet est de fournir une présence digitale moderne, claire et responsive permettant à l'entreprise de :

- présenter ses offres et domaines d'intervention;
- expliquer sa méthode d'accompagnement;
- valoriser ses engagements et sa différence;
- répondre aux questions fréquentes des prospects;
- faciliter les demandes de devis et les prises de contact;
- offrir une expérience utilisateur adaptée aux appareils mobiles et ordinateurs.

## Fonctionnalités

- Navigation fluide entre les différentes sections du site
- Présentation des services proposés
- Présentation de la méthodologie d'intervention
- Sections À propos, engagements, FAQ et contact
- Formulaire de demande de contact
- Fenêtres modales pour les mentions légales et la confidentialité
- Bouton de retour en haut de page
- Animations d'affichage avec AOS

## Technologies utilisées

- React 18
- Vite 5
- Bootstrap 5
- Bootstrap Icons
- AOS
- JavaScript
- CSS

## Prérequis

- Node.js
- npm

## Installation

Depuis le dossier du projet, installez les dépendances :

```bash
npm install
```

## Démarrage local

Lancez le serveur de développement :

```bash
npm run dev
```

Puis ouvrez l'adresse affichée dans le terminal, généralement `http://localhost:5173`.

## Build de production

Générez la version optimisée du site :

```bash
npm run build
```

Les fichiers de production seront disponibles dans le dossier `dist`.

## Aperçu de la build

```bash
npm run preview
```

## Structure principale

```text
src/
├── components/     # Sections et composants React
├── data/           # Contenus dynamiques du site
├── styles/         # Feuille de styles principale
├── App.jsx         # Structure générale de l'application
└── main.jsx        # Point d'entrée React
```

## Informations à personnaliser

Avant mise en production, vérifiez les informations suivantes :

- adresse, téléphone et e-mail de contact;
- ville, adresse et coordonnées géographiques;
- URL canonique du site;
- contenu des mentions légales;
- politique de confidentialité;
- textes et coordonnées présents dans les métadonnées SEO;
- images issues de sources externes.
